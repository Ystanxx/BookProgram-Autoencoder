# Autoencoder NIR光谱降维及特征重构系统

## 项目简介

本项目实现了基于**单隐层Autoencoder**的近红外（NIR）光谱降维系统，用于**8种农产品光谱数据的无监督降维和特征重构**。

### 核心特点

- **无监督学习**: 不需要标签，自动学习光谱数据的低维表示
- **高效降维**: 737维 → 100维，压缩率7.37倍，节省86.4%空间
- **精确重构**: 从100维潜在特征高质量重构原始737维光谱
- **农产品识别**: 支持红豆、当归、胡萝卜、大蒜、生姜、人参、大豆、小麦
- **产地区分**: 区分国产和进口农产品的光谱差异
- **可视化分析**: t-SNE、PCA潜在空间可视化

### 模型架构

```
输入 (737维NIR光谱)
    ↓
编码器 Encoder
    └─ Linear(737 → 100) + SELU
    ↓
潜在特征 Latent Features (100维) ← 压缩表示
    ↓
解码器 Decoder
    └─ Linear(100 → 737) + SELU
    ↓
重构输出 (737维NIR光谱)
```

## 技术细节

### 数据集

- **样本数量**: 400个（每种农产品50个）
- **农产品种类**: 8种（红豆、当归、胡萝卜、大蒜、生姜、人参、大豆、小麦）
- **光谱维度**: 737个波段点（9100-3900 cm⁻¹）
- **产地类型**: 国产、进口
- **数据类型**: 模拟NIR光谱数据（带有产地特征差异）

### 模型配置

- **激活函数**: SELU（自归一化激活）
- **损失函数**: 均方误差（MSE）
- **优化器**: Adam（学习率: 0.001）
- **批次大小**: 32
- **训练轮数**: 50
- **学习率调度**: ReduceLROnPlateau
- **早停耐心值**: 10轮
- **压缩比**: 7.37x（737 → 100）

### 评估指标

- **MSE** (均方误差): 重构误差的平方
- **RMSE** (均方根误差): 与原始单位一致的误差度量
- **MAE** (平均绝对误差): 平均重构偏差
- **PSNR** (峰值信噪比): 信号质量指标（dB）
- **Correlation** (相关系数): 原始与重构的相关性

## 应用场景

### 1. 数据压缩
- **存储优化**: 将737维光谱压缩到100维，节省86.4%空间
- **传输效率**: 减少数据传输量，提高速度
- **成本降低**: 降低存储和网络成本

### 2. 特征提取
- **下游任务**: 100维潜在特征可用于分类、回归等任务
- **迁移学习**: 预训练的编码器可迁移到其他任务
- **表示学习**: 学习光谱的低维有意义表示

### 3. 异常检测
- **质量控制**: 重构误差大的样本可能是异常产品
- **掺假识别**: 检测农产品掺假或污染
- **品质评估**: 评估产品质量一致性

### 4. 可视化
- **聚类分析**: t-SNE/PCA可视化不同农产品的分布
- **产地溯源**: 可视化国产vs进口的差异
- **质量监控**: 监控批次间的光谱变化
